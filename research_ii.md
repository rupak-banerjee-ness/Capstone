*   **[CrackSQL (weAIDB)](https://github.com/weAIDB/CrackSQL)**: An LLM-based SQL dialect translation system ideal for converting Oracle/SQL Server stored procedures and queries to PostgreSQL syntax.
*   **[AIM (alecthomas)](https://github.com/alecthomas/aim)**: An AI-assisted schema migration generator that automatically tests and verifies generated SQL against an ephemeral database before execution.
*   **[Text-to-SQL Agent (shreyabaid007)](https://github.com/shreyabaid007/text-to-sql-agent)**: A production-ready full-stack boilerplate featuring LangGraph, FastAPI, PostgreSQL, and built-in Human-in-the-Loop UI patterns.
*   **[LangGraph-SQL-Agent (Shreyash-Gaur)](https://github.com/Shreyash-Gaur/LangGraph-SQL-Agent)**: A reference implementation demonstrating self-correction loops, relevance routing, and database syntax error handling within LangGraph workflows.
*   **[Oracle AI Developer Hub (oracle-devrel)](https://github.com/oracle-devrel/oracle-ai-developer-hub)**: Contains a highly relevant multi-agent migration harness walkthrough demonstrating batch data processing and structural validation.
*   **[Data Validation Tool (GoogleCloudPlatform)](https://github.com/GoogleCloudPlatform/professional-services-data-validator)**: An open-source Python CLI based on Ibis for automated row, schema, and column-level data validation between heterogeneous source and target databases.
*   **[Oracle-to-Postgres (MIT-LCP)](https://github.com/MIT-LCP/oracle-to-postgres)**: A Python utility demonstrating how to use SQLAlchemy as an intermediary to map data types and migrate batch data directly from Oracle to PostgreSQL.
